# Shelfcraft Design System

Original identity. Informed by the *structure* of the reference (calm neutral canvas, card-based wizards, purposeful empty states, single accent color) but with distinct name, palette, type, iconography and logo.

## Identity
- **Name:** Shelfcraft — "craft the shelf your product sits on".
- **Logo:** geometric mark — three stacked rounded bars forming a shelf with an offset spark (inline SVG, `frontend/src/components/brand/logo.tsx`). Original work.
- **Voice:** direct, specific, never hype. Every AI output is labeled with the provider/model that produced it.

Rules: one primary action per view; violet only for actions that call an AI provider; no decorative gradients (a single subtle radial on the dashboard hero is the only exception).

## Typography
- **Display / headings:** Bricolage Grotesque (OFL, Google Fonts), 600–700, tight tracking (-0.02em).
- **UI / body:** Geist (OFL), 400/500. **Mono:** Geist Mono for IDs, sizes, prompts.
- Scale: 12 / 13 / 14 (base UI) / 16 / 20 / 24 / 30 / 36.

## Spacing, radius, elevation
- 4 px base grid; page gutter 24 px (16 px on tablet-portrait); section gap 32 px.
- Radius: `--radius: 10px` (cards 14, inputs/buttons 10, chips 999).
- Shadows: `xs` hairline + 1 px drop for cards on hover only; popovers `0 8px 24px -8px rgb(0 0 0 / .18)`.

## Layout
- Sidebar 248 px, collapsible to 60 px icon rail (persisted). Auto-collapses < 1024 px.
- Top bar 52 px: breadcrumb (left), ⌘K search, job tray (live count), notifications, theme toggle.
- Content max-width 1200 px for forms/wizards; full-width for library, editor, factory.
- Editor: left tools rail 52 px · layers panel 260 px · canvas (sunken bg, checkerboard for transparency) · properties panel 300 px.

## Components (shadcn/ui-style, Radix primitives, Lucide icons @ 1.75 stroke)
Button (primary / secondary / ghost / outline / ai / destructive; sm 32 / md 36 / lg 40), Input, Textarea, Select, Combobox, Chips input, Color swatch input, Dialog, Sheet (drawer), Popover, Tooltip, Tabs, Dropdown menu, Toast (sonner), Skeleton, Badge, Progress, Empty state (icon + title + one sentence + one CTA), Option card (wizard), Data table, Dropzone, Before/after slider, Provider badge ("Generated by ollama · qwen2.5:3b").

## States
- **Loading:** skeletons shaped like the final content; jobs show queued → running (progress %) → succeeded/failed with retry.
- **Empty:** never blank; one-sentence purpose + one CTA.
- **Error:** inline message with cause and recovery action; provider errors name the provider and show "Try another provider".
- **Disabled AI:** when no provider is available, AI buttons show a tooltip linking to Settings → Providers; non-AI tools keep working.

## Responsive
Desktop ≥ 1280, laptop 1024–1279, tablet 768–1023 (sidebar becomes overlay sheet; editor side panels become toggleable sheets). Phone is not a target but must not break.
